- Hardware: Kaggle, one NVIDIA T4, as reported for the run. The uploaded environment records `device="cuda"` and `dtype="torch.float16"`; it does not independently record the GPU model.
- Inference: one request per `predict` call, with all of that request's questions processed together; fp16 CUDA autocast, with a float32 retry if answer probabilities are nonfinite. cuDNN is disabled on T4 by the engine. The published engine selects bf16 autocast on GPUs with compute capability 8 or newer.
- Capacity: maximum input length **8,192 tokens**; overlength and unsupported requests are refused without truncation. Choice questions accept 2–255 options and score questions 2–10 levels. The scored run has **139,589 answered** and **589 unsupported** requests, with no errors or pending requests.
- Reported latency: median **18.8 ms**, mean **35.0 ms**, p95 **85.1 ms** per request, including tokenization. Official leaderboard latency remains subject to the maintainers' measurement.
- Training overlap disclosure: the [model card](https://huggingface.co/paulprt/prism-system-one/blob/7276ec2120a66a854e97702e12df6e667389e8b5/README.md#training-data-notes) declares training-source overlap with some public benchmark datasets, including ESCI, BANKING77, CLINC, and ARC; only their training splits were used.
