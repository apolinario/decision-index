# Submissions

Bekko System One v0 consists of very small English encoder models (17M, 68M and 400M), fine-tuned from Ettin rerankers for Choice, Noul and Score decisions. They evaluate supplied alternatives and return probabilities or numeric scores without generating text. Model links below pin the exact evaluated checkpoints.
