# Decision Index submissions

## Seb-9B-v2

- Model: [ironbcc/Seb-9B-v2](https://huggingface.co/ironbcc/Seb-9B-v2), Apache-2.0, Qwen3.5-9B fine-tune.
- Complete public 0.3 results: [run package](https://huggingface.co/datasets/ironbcc/seb-9b-v2-decision-index/tree/main/runs/seb-9b-v2-0.3), including `scores.json`, compact `results.jsonl.gz`, validation, environment/provenance and inference source. Official scorer: **140,178/140,178 scoreable requests present, `complete: true`, zero pending requests and zero errors**. Of those, 140,177 are answered and one is unsupported under the declared capacity limit.
- Public index: **59.16** (raw 69.37), self-scored. No private/Full score claimed; requesting maintainer private evaluation and latency validation. Public Decision Index skill data were used in training, so this public result is not an independent holdout.
- Kit: [`9eb2dbe2a358004c8782c66e40a83ac07b953fec`](https://github.com/apolinario/decision-index/commit/9eb2dbe2a358004c8782c66e40a83ac07b953fec), `http` engine, edition 0.3.
- Hardware: NVIDIA RTX PRO 6000 Blackwell Workstation Edition, 96 GB per GPU. Original indexed benchmarks used two independent single-GPU PyTorch BF16 shards; 30,091 missing non-index requests were completed with vLLM BF16 on one GPU. All original 110,520 result rows retain identical answers/statuses; runtime and scheduling differences are disclosed. Raw results include excluded/unscored rows, so raw row counts differ from scoreable counts.
- Inference: fixed candidate-v2 prompt, thinking disabled, full candidate probabilities normalized from next-token scores, no truncation or option filtering. Context 32,768 tokens; payload cap 262,144 characters. vLLM 0.30.0: processed_logprobs, max_logprobs=20, generation_config=vllm, max_num_seqs=64, gpu_memory_utilization=0.45; readout max_tokens=1, temperature=1, top_p=1, top_k=-1, allowed_token_ids restricted to all supplied option keys.
- Reproduction: `REPRODUCTION.md` and `inference/` in the results directory document exact commands, pinned model revision, weight/source hashes, ordinary single-stream serving and the bounded concurrency wrapper used for completion. Aggregate run latency mixes runtimes/concurrency and is not a single-stream latency measurement.
