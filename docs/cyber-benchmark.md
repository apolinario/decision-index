# esdb parent dataset

the v0.1 parent supplies the selected native incidents, captures and program components used to build v0.3. it is retained for construction and source verification. its original policy panel has a 99.1% majority baseline and is unsuitable for ranking models.

use the matched policy cases, endpoint investigation cases and expanded network sources described in the [v0.3 proposal](cyber-v0.3.md). the local parent build needs the collected sources and pinned prior-use and policy-analysis records. source redistribution and a portable public rebuild remain pending.
